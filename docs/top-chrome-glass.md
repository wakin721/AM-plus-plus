# 顶部液态玻璃

顶部玻璃沿用“手机液态玻璃”开关和面板模糊半径。首个适配版本为 Apple Music
`7.0.0-beta (1606)`，要求 Android 13 或更高版本；其他 profile 保持原来的顶部材质。

覆盖原生 `Aa.x` 顶部控件家族：返回、新增播放列表、更多操作按钮，以及其下拉菜单。
仅替换背景绘制，保留原生图标、菜单项、点击、无障碍语义和按压反馈。
按钮使用圆形镜片，菜单使用 24dp 圆角；共享底部玻璃的 Backdrop 折射 shader。
白色页面上的变化以边缘折射与高光为主，滚动到图片或文字上方时可看到背景采样。

## 坐标与采样

原生 DrawScope 的节点坐标转换到屏幕坐标，包含父图层变换与弹窗窗口原点。
不能使用 RecordingCanvas 的矩阵推算按钮位置，因为它不包含祖先 RenderNode 的位置。
材质节点在 pre-draw 时刷新坐标，原生控件复用绘制缓存时仍可跟随页面移动。

底层页面通过软件遍历生成半分辨率的采样图；采样期间省略玻璃消费者及其图标，
避免把玻璃自身录回背景或形成递归 RenderNode 图。硬件封面位图在采样期间转换为软件副本，
缓存上限 16MiB。背景有变化时最多更新 20 次/秒，模糊与折射仍在 GPU 上执行。
无可见消费者、页面隐藏或玻璃关闭时停止采样。

首帧先绘制原生颜色，采样就绪后刷新同一个材质节点。采样或 shader 失败时将该节点
改为原生颜色背景，保留内容与操作；根窗口脱离时移除监听并释放位图和 RenderNode。

## 验证

`scripts/verify-host-profile.py <1606 APK> --glass` 校验 `chromeGlass` 的完整方法签名、
字段类型和 static 契约。`GlassCaptureGuardTest` 验证嵌套采样、异常恢复与线程隔离。
GitHub Actions 执行完整 Android 编译、单元测试、lint 和 APK 打包。
